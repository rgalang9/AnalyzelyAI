# Analyzely

An AI-powered data cleaning and analysis tool. Upload a dataset, let the AI find and fix bad data, then explore it with smart charts and an AI chat agent.

## Features

- **Upload datasets** – drop in your data file (CSV, Excel, etc.)
- **AI error scan** – detects wrong, missing, duplicate, or inconsistent data
- **Clean status check** – shows green when the dataset passes the scan
- **Dataset viewer** – scroll through the full dataset with issues highlighted
- **Auto-clean** – AI suggests and applies fixes to errors
- **AI chat agent** – ask questions and tell the AI what you want to do with your data
- **Smart graphs** – AI recommends and generates the best chart for your data type

## How It Works

1. Upload your dataset
2. AI scans it for errors
3. Answer a few questions about your data and goals
4. Review and auto-clean flagged issues
5. Chat with the AI to analyze your data and generate graphs

## Tech Stack

| Tool | What it does |
|------|--------------|
| Next.js | Web app framework (frontend + backend) |
| Supabase | Database, authentication, and file storage |
| Docker | Packages the app so it runs the same everywhere |
| Vercel | Hosts and deploys the app |
| Claude API | Powers the AI scanning, cleaning, chat, and chart suggestions |
